# IRON FRONT｜鐵幕前線

**v2.2.0 · 單人戰役正式版**
在電腦或手機上指揮基地、採礦、建造與生產部隊。單人戰役從西岸紅軍出發，雙人好友房則由兩名玩家各守一岸，勝負取決於誰能摧毀對方的指揮部。

單人戰役選定後立即計時。東岸藍軍會採礦、支付資源訓練步兵與生產裝甲部隊，並逐步擴大跨橋攻勢。單人戰場上方的「單人戰役」可重新開啟作戰模式選單。

## 開始遊玩

[正式版遊戲入口](https://ph0star.github.io/Iron-Front/) · [Cloudflare 備用入口](https://iron-front-duel.phostudy.workers.dev/)

房主建立好友房後，可分享 QR Code、邀請連結或 8 碼房號。受邀玩家入房後直接選擇視野並準備作戰。房間、戰場、生產圖例與結算會依你本局指揮的陣營顯示紅軍翼徽或藍軍盾徽。兩人各選「準備作戰」後開始。房間支援不同網路的電腦、手機，以及 PWA 獨立視窗。個人選單不影響對局時間。

- 房間中兩人都能選擇全圖或迷霧，變更後需重新準備。戰中從「雙人對戰」提議，對手在戰場上同意後同步切換。探索紀錄、敵建築最後所見與雷達均按陣營計算。
- 短暫斷線會暫停戰局；原裝置在同一瀏覽器重新開啟相同連結後恢復席位。60 秒後，仍在線的一方可以繼續等待或中止。完成一局後可互換陣營再戰。
- 首次加入需連網。頁尾顯示「離線就緒」後，斷網也能從「單人戰役」開新局。

### 戰場對講機

兩位玩家加入同一間正式房並開始對戰，即可使用戰場標題旁的「對講」。點一下可打字或傳快捷句，電腦也可按 Enter 開啟輸入框。長按按鈕或按住 V 錄最多 5 秒，放開送出，指標滑出或切到背景會取消未送出的錄音。首次錄音需要麥克風權限。手機請用公開 HTTPS 網址測語音，區網 HTTP 可測文字。

收聽預設為點擊播放，可選自動播放或靜音。最近 12 則訊息只保留在本局瀏覽器記憶體。房間透過既有遊戲連線傳文字，另開與席位及局數綁定的 WebSocket 即時轉送短錄音。斷線或結束對局會清除通訊紀錄並釋放麥克風。支援瀏覽器語音辨識的裝置另可選「語音轉文字」，確認結果後再送出。

### 本機或同 Wi-Fi 遊玩

需 Node.js 22 或更新版。在專案根目錄執行以下指令。

```sh
npm ci
npm test
npm start
```

本機使用 http://localhost:8080/ 。手機連同一 Wi-Fi 後，開啟終端機印出的區域網路網址；請先用該網址建房，邀請連結與 QR Code 才會指向可連線的主機。HTTP 區網網址可測對戰，安裝與離線驗收使用 HTTPS 或本機 localhost。可用 PORT 或 HOST 環境變數修改監聽設定。

### 對戰服務與部署

- `engine.js`、`terrain.js` 共用地形、單位、尋路、經濟與戰鬥規則。`server/match.mjs` 產生分陣營的戰場資料；`server/room.mjs` 管理席位、準備、倒數、提議、時間、重連與結算。
- `duel.js` 負責房間、邀請、WebSocket 連線及可見範圍，`game.js` 延用原本的戰場繪圖與操作。`test/` 包含規則與真實 WebSocket 整合測試。
- GitHub Pages 從 main 根目錄提供正式版 PWA，並連到 Cloudflare Worker `iron-front-duel` 的房間服務。Cloudflare 備用入口與 Pages 共用正式房間。測試分支部署至獨立的 `iron-front-duel-beta`。每個 8 碼房號由自己的 Durable Object 管理。更新時先跑測試，連到經授權的 Cloudflare 帳戶後，在根目錄執行 `npx wrangler deploy`。`wrangler.jsonc` 的建置步驟會自動執行 `node scripts/pack-assets.mjs`，只封裝公開遊戲資源。
- 前端若要獨立部署，可在 `duel-config.js` 指定 HTTPS 房間服務來源，並在 Worker 的 `FRONTEND_ORIGIN` 設定該前端的 origin。版本異動必須更新 `VERSION`、套件版本、`sw.js` 快取鍵；不相容的房間協定也要同步更新前後端協定號。
- 戰局保存在執行中的房間記憶體。斷線保席位適用於裝置與網路短暫中斷；重新部署或伺服器程序重啟可能終止該局。清除網站資料或跨瀏覽器無法取用原重連憑證。

## 單人操作

下載本版本並解壓縮，用桌面瀏覽器開啟 `index.html` 即可遊玩。手機可使用公開部署的網址。音效在第一次操作後啟用，行軍配樂可在右上角的音效面板開啟。

| 裝置 | 操作 |
| --- | --- |
| 電腦 | 左鍵點選或框選部隊，右鍵點地面移動、點敵軍攻擊。滾輪縮放，方向鍵平移，F 選全軍，H 返回基地。 |
| 手機 | 點選單位再點地面或敵軍。單指平移、雙指縮放。底部可開啟生產面板或選取全部作戰部隊。 |

## 版本與還原

正式版 v2.2.0 以通過實測的 v2.2.0-beta.2（`24b7c50`）為基礎，收錄單人敵軍採礦、生產與進攻，以及「單人戰役」與「雙人對戰」按鈕文字調整。上一個正式版本可由標籤 `v2.1.0` 取得。

正式版 v2.1.0 收錄戰場對講、手機橫向工具列與桌面標題字距調整，以通過實測的 v2.1.0-beta.3（`e5b7a65`）為基礎。

正式版 v2.0.0 以通過實測的 v2.0.0-beta.2（`5e1d3a5`）為基礎。前一個單人正式版 v1.1.0 可由提交 `87cd833` 還原。Git 標籤 `v1.0.0` 對應首個可玩版本。取得儲存庫後，執行 `git switch --detach v1.0.0` 即可查看該版；要從這個版本繼續開發，執行 `git switch -c work-from-v1 v1.0.0`。

## 程式與資產

| 路徑 | 用途 |
| --- | --- |
| `index.html`、`style.css` | 戰場介面、繁體中文操作面板、響應式排版 |
| `engine.js` | 即時模擬、尋路、經濟、建造、交戰與勝敗 |
| `game.js` | 鏡頭、指令、互動、畫面更新與雷達 |
| `terrain.js`、`sprites.js` | 地形、建築、車輛與士兵的原創繪圖程式 |
| `sound.js` | Web Audio 合成音效與行軍配樂 |
| `icons.js`、`assets/insignia.svg` | 介面圖示與遊戲識別 |

遊戲直接執行靜態 HTML、CSS 與 JavaScript。GitHub Pages 可從 `main` 分支的根目錄部署。

## 安裝與離線遊玩

[開啟遊戲](https://ph0star.github.io/Iron-Front/)，首次連網並等待頁尾出現「離線就緒」。支援安裝提示的瀏覽器可用右上角安裝按鈕；iPhone 或 iPad 請用 Safari 的分享選單選「加入主畫面」，若顯示「作為網頁 App 打開」請開啟。首次從主畫面開啟也請連網等候離線就緒。

離線可開始完整戰役。關閉遊戲或重新載入會重新開局。新版會在舊版視窗全部關閉後接手。維護時請同步更新 VERSION 與 sw.js 的快取版本及檔案清單。
